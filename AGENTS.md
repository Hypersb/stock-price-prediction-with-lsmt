# Agent instructions

This repository is a professional portfolio project owned by the human repository author.

## Git authorship policy

- Use the repository owner's existing local Git identity (`git config user.name` / `user.email`).
- Never modify `user.name` or `user.email`.
- Never add AI/coding-agent attribution of any kind.
- Never add `Co-authored-by` for Cursor, Claude, ChatGPT, Copilot, or any coding agent.
- Never add `Generated-by` / `Generated by` metadata.
- Never set the coding agent as author or committer.
- Commit messages must begin exactly with lowercase `fix: `.
- Do not push unless the human explicitly asks.

A local `commit-msg` hook under `.githooks/` strips Cursor co-author trailers if a tool inserts them.

## Research integrity

- Do not fabricate metrics, news, monitoring, or user data.
- Do not present placeholders as real results.
- Prefer negative/null empirical outcomes over impressive fiction.
